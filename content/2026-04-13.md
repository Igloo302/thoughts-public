### 关于 Managed Agents 的思考
![[AI编程现状-2026-04-13.png]]
managed agents 主要的创新是 agent 从单体耦合容器变成了一个**组件化、可拆分和可进化**的架构。

我自己尝试在不同的环境部署/迁移几次 OpenClaw 之后，这个问题其实挺明显的：
- **环境信息不同导致思维混乱**（例如我把 Claw 从 Windows 迁移到 Mac）
- **环境需要重建**（以前会的、以前有的工具换了环境之后，出现了未曾经历的报错）
- **外部的文件系统变了**（原来能找到的文件，现在不见了）

managed agents 定义了一个固定的接口，内部 Harness 可换、Sandbox 可换、模型可换，只有代表记忆的 Session 是持久化的：组件越换越先进，但是不影响上层业务。

但是 managed harness 并没有给出越来越长的 Session / 记忆如何读取的问题——只给了底层数据和接口，没给方案。但是这应该是未来的发展方向。

同时也对库的管理有了新的思考：
- 0-Inbox 积累了 24 个待整理文件，需要定期清理
- 使用 PARA 方法论的结构已经初步形成
